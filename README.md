국민대학교 AI빅데이터융합경영학과 · 데이터사이언스전공 복수전공

### 이런 걸 만듭니다

난임 시술 통계, 청년정책, 산불 피해지 위험도, 글로벌 무역 통계, 관광 데이터 — 지금까지 만든 서비스는 모두 같은 문제에서 출발했습니다.
**정보는 이미 공개돼 있는데, 정작 필요한 사람은 다음에 무엇을 해야 할지 모른다**는 것입니다.

그래서 검색 결과를 보여주는 데서 멈추지 않고, 조건 추출 → 검색 → 필터링 → 적격성 검증 → 준비 절차까지 하나의 흐름으로 잇는 것을 목표로 합니다.

또 하나의 원칙은 **사실과 문장을 분리하는 것**입니다. 금액·기간·자격 같은 사실은 DB와 규칙 엔진이 책임지고, LLM은 조건 추출과 문장 다듬기만 맡습니다. 덕분에 API가 죽어도 서비스는 계속 동작합니다.
